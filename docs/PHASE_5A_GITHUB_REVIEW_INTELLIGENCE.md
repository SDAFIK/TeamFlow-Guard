# Phase 5A — read-only GitHub review intelligence

GET /api/projects/:workspace/github-review?task=:uuid uses existing authenticated workspace snapshot, explicit server mapping, and repository-scoped GitHub App token. TEAMFLOW_GITHUB_REVIEW_MAPPINGS is a JSON array of workspace_id, pull_number, task_id, github_reviewer_id (numeric immutable GitHub user ID), reviewer_id (workspace member UUID). Exactly one mapping per task is required for this endpoint. Demo workspaces cannot call it. No write or external AI call. Pull request current state and requested reviewers establish whether review is pending; timeline review_requested timestamps establish wait duration. Full first page (100) or ambiguous history abstains. Team reviewers and pagination are not supported. PR closure/draft/removal returns inactive/not requested. This is on-demand observation, NOT signed webhook ingestion, persistent evidence, or recovery proposal integration. Live GitHub App remains unconfigured; mocked/domain tests do not prove live delivery. Next: scoped service-only persistence, signed lifecycle webhook reconciliation against current GitHub state, DB ordering/idempotency tests and recovery integration. No migrations or production changes in this checkpoint.

Official references: https://docs.github.com/en/rest/pulls/review-requests and https://docs.github.com/en/rest/using-the-rest-api/issue-event-types
