# TIC snapshot integration checkpoint
Read-only GET /api/projects/:workspace/intelligence?task=:uuid uses the existing authenticated workspace snapshot. No database writes, provider calls, or approval changes. Features are derived from task state, tracked-branch recent CI evidence, open non-draft review evidence, graph successors, deadline and current voluntary capacity. Missing evidence is null, not zero. Capacity is an estimate proxy, not productivity. Scores are available only for fictional demo workspaces with complete in-domain inputs; real workspaces receive observations and an explicit abstention. No UI redesign. No production release. Tests cover feature derivation, missingness, recovery, branch isolation, real-workspace abstention and out-of-domain inputs. Live GitHub/AI and historical real-world model validation remain independent gates.
