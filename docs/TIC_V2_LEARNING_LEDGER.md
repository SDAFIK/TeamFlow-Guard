# TIC V2 prospective learning ledger
Workspace owners explicitly enable collection and can purge it. Managers and owners capture an unfinished task once, before its deadline, from authoritative database records. Existing tasks created before the migration have unknown creation time and are not backfilled. Features are derived from recent signed CI and active reconciled PR evidence, dated voluntary availability, task estimates, task creation time, deadlines and unfinished graph. No task titles, names, raw code, private messages, or personnel ratings appear in the export. One sample per task. Deadline changes and archives exclude the sample; task completion records an actual timestamp. Owner export includes only completed or elapsed-deadline samples, pseudonymous project/task groups, observed times and numeric features. No automated activation, no data shared across workspaces by the server. Previously downloaded exports cannot be revoked by deleting the ledger. Do not commit exported data to the public repository. Real candidate training must use separate project groups and chronological validation. This does not prove real-world accuracy; no actual learning data was gathered during development.
