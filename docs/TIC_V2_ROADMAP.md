# TIC V2 roadmap and controls
Checkpoint 1: read-only project intelligence, authenticated snapshot, critical unfinished effort path, deadline pressure proxy, evidence-backed task explanations, role controls. Estimates are not remaining duration; no resource/calendar-aware schedule yet.
Next gates: (1) complete parent PR14 isolated acceptance; (2) expanded feature schema and timestamped outcome labels with opt-in, no personal productivity scoring; (3) project/time-separated training and validation, compare logistic/random forest/XGBoost against heuristics, calibration and recall at an agreed false-positive budget; (4) recovery simulation with dated capacity and remaining effort, constrained actions; (5) shadow model candidate evaluation, versioned immutable artifacts, manager/admin promotion and rollback, never automatically activate a synthetic model for real teams; (6) accessible user explanations and model control panel; (7) actual GitHub/Gemini and multi-user release acceptance. No production writes or paid resources.
Learning policy: use consented task-level snapshots before outcomes, completion timestamps and deadline revisions; freeze label definition, record intervention/approval separately from outcome, avoid leakage and individual ratings. Retrain candidate offline on drift or enough new labels; reject candidate without adequate held-out data, calibration and safety checks; promotion requires reviewed artifact and green CI. Model changes never authorize task changes. Real dataset and training not implemented in checkpoint 1.
