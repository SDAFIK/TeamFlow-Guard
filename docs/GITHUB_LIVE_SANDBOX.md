# Dedicated GitHub App live sandbox
This branch is isolated from production. The synthetic workflow runs only on codex/github-live-sandbox when its fixture or workflow changes, never deploys, and accesses no database or secrets. After the dedicated App is registered and installed, connect an isolated non-demo workspace on a disposable database with tracked branch codex/github-live-sandbox. Map the workflow ID to its sandbox task. Keep actual production workspaces and their data untouched.
Registration: private GitHub App, repository Metadata read, Actions read, Pull requests read. Activate webhook only once the isolated HTTPS receiver is ready; subscribe workflow_run, pull_request, pull_request_review. Configure a random signing secret directly in GitHub and the receiver. Install only the explicitly selected test repository (SDAFIK/TeamFlow-Guard). Do not reuse the ChatGPT GitHub connector installation.
First live journey: update fixture to fail, verify signed GitHub workflow_run completed delivery and task risk in isolated database; update to pass and verify resolution. Verify delivery deduplication and older event handling. Then use a separate sandbox PR and mapped reviewer to validate review lifecycle. No real production data, automated plan edits or paid resources.
Server-only configuration: GITHUB_APP_ID, GITHUB_APP_PRIVATE_KEY, GITHUB_APP_WEBHOOK_SECRET, TEAMFLOW_GITHUB_APP_BINDINGS, TEAMFLOW_GITHUB_CI_MAPPINGS, TEAMFLOW_GITHUB_REVIEW_MAPPINGS, TEAMFLOW_GITHUB_INGEST_KEY, isolated NEXT_PUBLIC_SUPABASE_URL and publishable key. Never commit secrets.
