# Experimental TIC model card

Version: tic-synthetic-logistic-v2. CPU-only logistic regression trained with standard-library Python; no external service. Reproduce with python scripts/train-tic-model.py. Six bounded features, 60 synthetic projects (100 rows each), disjoint groups: 36 training, 12 validation, 12 held-out test. Standardization uses training data only. Threshold 0.28 maximizes validation F1; test is never used to choose threshold. Test default threshold: accuracy .735, precision .690323, recall .28382, F1 .402256. Selected threshold: accuracy .7025, precision .524155, recall .575597, F1 .548673. Brier .183861 vs constant prevalence .217417. The model is experimental, not production-ready, and not a calibrated real-world probability. Synthetic labels are generated from assumed feature relationships. No causal inference or individual performance scoring. The inference function abstains outside the synthetic feature bounds and returns logit contributions, not causal explanations. Do not use it to approve or change plans. No integration into production risk detection yet. Future work: consented historical outcomes, chronological/project holdout, missingness, simple heuristic baseline and alternative classifiers, calibration and operational false-negative/false-positive thresholds; require real-world validation before enabling decisions.
